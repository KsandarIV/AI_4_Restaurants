2 · Modelli e dipendenze

Modelli (locali)

LLM gemma4:12b via Ollama (macchina BE) · STT faster-whisper tiny · TTS Piper it_IT-riccardo-x_low (voice/models/) · VAD Energy default.

Dipendenze

Unificate in setup/requirements.txt: fastapi, uvicorn, httpx, pydantic, numpy, faster-whisper, piper-tts, onnxruntime (+ BE: langchain/langgraph/sqlalchemy · CHAT: streamlit/spacy).

3 · Logica chiave

AspettoScelta
LatenzaToken LLM → TTS in overlap; sintesi per-frase; shortcut tool senza giro LLM
InterruzioneBarge-in: nuova voce invalida turno, svuota coda audio, notifica client
ResilienzaRetry/backoff HTTP, timeout ovunque, code bounded, setup auto-riparante, graceful shutdown
PrivacyScrub PII lato Voice prima dell'invio; customer_id anonimo verso il BE
Contratto BEPOST /api/chat/stream (SSE), availability, CRUD /api/reservations/{booking_code}, /api/menu, /api/info

4 · Punti di forza / deboli

Forza

Voce naturale interrompibile · on-premise (zero costi API, dati in casa) · resiliente e auto-installante · testabile senza rete (stub BE + 13 test).

Deboli e mitigazioni

Primo token lento (inferenza BE completa → mitigato con shortcut) · STT tiny su CPU (upgrade con GPU) · nessuna auth su WS/BE (solo LAN demo; token in produzione).
